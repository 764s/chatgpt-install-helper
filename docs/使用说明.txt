ChatGPT 安装助手 1.6.1

使用
1. 启动能正常访问 OpenAI 的网络/代理。
2. 关闭正在运行的旧版安装助手，双击 ChatGPTInstaller-1.6.1.exe。窗口自动检查官方版本和本机缓存。
3. 点击“安装 / 重装”或“更新”，先准备并校验安装包；已有匹配的完整缓存时直接复用。这个阶段可以继续运行 ChatGPT / Codex 任务，不会申请管理员权限、关闭应用或自动安装。
4. 界面显示“准备就绪，尚未安装”后可以继续等待。任务完成并保存工作后，再点击右侧“立即更新”或“立即安装 / 重装”。
5. 程序重新核对官方版本和缓存，然后申请 Windows 管理员授权并执行安装；此时 ChatGPT / Codex 可能会关闭。
如果只想了解有无更新和累计更新内容，点击“仅检查更新”即可，不下载完整包或部署。

程序是单文件联网安装器，可复制到其他电脑使用。运行不需要 Python、Node、winget 或额外安装 .NET SDK；使用 Windows 自带的 .NET Framework、Windows PowerShell 5.1 和应用部署组件。

添加到 Codex 全局侧栏（可选，只需首次配置）
1. 打开“Codex 侧栏入口”页，点击“添加 / 修复入口”。
2. 助手自动保存独立副本、注册本地插件并启用，不需要手动改配置、下载仓库或安装运行时。
3. 等现有任务结束后，完全退出并重新打开 ChatGPT。在侧栏“更多”中找到“ChatGPT 更新器”，可将它固定到侧栏。
4. 点击侧栏入口即可看到当前版本、官方版本及下载 / 安装进度。底部小灰字“打开所在文件夹”会在资源管理器中打开更新器所在目录；需要查看累计更新内容、日志、网络设置或覆盖重装时，可从这里双击 ChatGPTInstaller.exe。
此入口是全局侧栏插件，不能指定紧贴官方蓝点的位置，也不替换官方蓝点的点击行为。
配置成功后，入口使用固定用户目录中的副本；原来下载位置的 EXE 可以删除。将来升级安装助手时，运行新 EXE 并点击添加 / 修复入口，更新副本和插件。
ChatGPT 的正常更新、助手内“安装 / 重装”都会保留独立副本、插件来源和用户配置。主动清除相关用户目录、移除插件或官方插件接口变化不在此保证范围内。
“移除侧栏入口”移除本插件及其专用来源，保留安装助手、下载缓存和日志。移除后不会在下一次 ChatGPT 更新时自动恢复。
如果入口未出现，先重新打开 ChatGPT；若找不到 Codex 随附组件或其版本不支持插件命令，助手会明确提示，可继续使用独立 EXE 更新 ChatGPT。
从 1.5.1 起，页面内容变化后自动生成新资源地址，标题旁显示更新器版本。升级插件后仍需客户端重新加载插件；若仍看到旧界面，等任务结束后完全退出 ChatGPT（包括后台/托盘）再打开，本版标题旁应显示 v1.6.1。

侧栏更新
• 打开页面自动检查版本。点击“下载更新”开始下载和校验，页面显示阶段、百分比及下载速度；默认下载完成后等待点击“应用更新并重启”。
• “准备完成后自动安装并重启”默认不勾选，只对本次准备有效。勾选后，无论是复用缓存还是新下载，校验完成即进入安装，不判断 Codex 任务是否结束，请先结束任务。准备期间可以取消勾选；取消或失败后不会自动重试安装。
• 应用更新前仍会重新验证官方版本、包签名和缓存。需要时会出现正常的 Windows 管理员授权；取消授权或安装失败会保留错误提示及有效缓存，不宣称更新完成。
• 侧栏发起的安装核对成功后自动请求重新打开 ChatGPT；失败时不自动重启。完整窗口直接发起的原有安装流程仍由你选择何时打开 ChatGPT。
• 页面和完整窗口共用一个助手进程与一套操作状态。关闭页面、切换聊天或隐藏从侧栏打开的完整窗口，不会取消已开始的下载 / 安装；可在页面点击取消停止下载或安装前检查。
• 隐藏且空闲、页面停止访问两分钟后助手会退出，缓存保留。之后再次点击下载会重新检查版本、复用有效缓存并校验；自动安装勾选不会继承到新进程。

功能
• 每次操作实时读取与官方 App 相同的生产渠道更新清单，按清单版本选择安装包，不固定 ChatGPT 版本号。
• 使用版本专属下载地址；不再把可能滞后的通用直链当作最新版。清单失败、产品身份不符或目标包不可用时，明确报错，不退回旧版本并宣称最新。
• 自动选择 x64 / ARM64 安装包。
• 直接从 OpenAI 官方下载 MSIX 和离线许可证，不打开 Microsoft Store。
• 预下载内置在安装 / 重装与更新中。默认完整下载、签名和许可证校验通过后等待应用；只有侧栏明确勾选本次自动安装时才会自动继续。
• 准备好后可以等待任务结束，也可以关闭安装助手。重新打开后，再点击相应的安装 / 更新按钮，会重新检查版本并复用有效的完整缓存；校验后仍等待你点击立即安装。
• 自动识别 HTTP 代理环境变量、Windows 系统代理/自动配置、TUN，以及常见本机 HTTP 代理端口。必要时可在“网络设置”填写 HTTP 代理地址。
• 显示当前版本、官方版本、下载百分比、容量、速度和安装阶段。Windows 提供安装百分比时显示实际值，否则显示“进行中”。
• 下载自动重试；中断或取消后，再次点击可续传。官方包发生变化时重新获取，避免拼接不同版本。
• 同时核对清单版本、服务器包元数据和下载包内版本。下载结束及实际安装前重新读取官方清单；若下载或等待期间出现新的发布，先停止部署，提示重新准备新版。
• 点击立即安装时还会重新验证缓存包、Windows 签名和许可证，防止等待期间缓存损坏或被移除。
• 已是最新版时，“更新”不重复准备或安装。未安装新版时，“更新”会准备最新版安装包，等待点击立即更新。
• “安装 / 重装”使用覆盖部署与重新注册，不执行清空数据式卸载。检测到更高的本机版本时保留该版本。
• “仅检查更新”读取本机版本、官方包版本和发布说明，报告有更新、暂无更新或无法判断；不下载完整安装包、不申请管理员权限、不安装或改动应用。
• “更新内容”页按本机版本至官方包版本的范围累计官方已公布的桌面版说明，可复制检查结果，也可打开完整官方日志。窗口可以放大阅读。
• 执行操作时，仅当前操作按钮深色高亮并显示进行中，其余操作置灰。完成、取消或失败后，三个按钮恢复普通状态。
• 安装成功后，确认区明确显示完成结果和“打开 ChatGPT”，不再显示等待下载；取消按钮在空闲时隐藏。最大化窗口时内容居中，避免按钮和文字过度拉伸。
• Windows 暂时无法关闭正在使用的 ChatGPT 时，等待 5 秒后自动重试一次，复用已验证的准备包。仍失败时显示明确的退出步骤和“重试更新 / 安装”；不会无限重试，也不会对所有安装错误都重试。
• “本次记录”只显示当前操作的简明进度和结果；完整异常堆栈仍保留在日志文件中，可使用“复制完整日志 / 打开完整日志”。开始新操作不会删除历史日志。

累计更新内容的范围
• 官方日志不一定覆盖每个 Windows 构建号。程序按官方明确标注的发布批次筛选，保留官方原文和来源；条目中的平台限制以原文为准。
• 未公开的变更、未标版本的公告和同一批次内的小构建差异无法准确归属，不会生成或猜测内容。日志没有对应条目、尚未覆盖目标版本或获取失败时，会明确说明；这些情况不代表没有变更。
• 尚未安装时，列出最近 3 条有版本号的适用桌面版说明作为参考。已是官方生产渠道当前版本或更高版本时，没有待安装的累计更新范围。
• 安装、更新和仅检查共用同一官方生产渠道清单。清单由官方维护，可能存在 CDN 缓存或发布延迟；本工具不会把某次查询到的版本写死。

需要知道
• 目前支持 Windows 10 2004（19041）或更高版本及 Windows 11；新版 ChatGPT 以后提高系统要求时，以安装包清单为准。
• 点击上方“安装 / 重装”或“更新”只进入下载准备，可以与 Codex 任务同时进行。点击右侧“立即安装 / 更新”后才会进入可能关闭 ChatGPT（包含 Codex）的部署阶段，请在点击右侧按钮前结束任务、保存工作。
• 不会检测任务是否结束。默认等待你应用；勾选本次自动安装则下载校验完成后直接安装并重启，可能中断仍在运行的任务。实际安装前仍需要联网复核官方版本。
• 首次安装按官方离线部署方式安装许可证并为本机预配应用，之后为当前用户注册；新的 Windows 用户也可能获得该预配应用。已安装用户的“更新”直接更新当前用户应用。
• 管理员授权是 Windows 对此官方应用的要求。若公司策略禁止程序运行、PowerShell 组件或应用部署，需要 IT 授权；工具不能消除此限制。
• 若用另一个管理员账户批准，程序会尝试为原用户完成注册；系统仍拒绝注册时，界面报告未完成，可能需要注销并重新登录 Windows。
• 面向官方新版 ChatGPT（Chat、Work、Codex），包标识目前为 OpenAI.Codex；已有 Codex 可沿此渠道更新。旧 ChatGPT Classic 不会被卸载，可能与新版并存。
• 本工具是非官方辅助程序，EXE 未做商业代码签名，Windows 可能显示未知发布者提示。下载的 ChatGPT 安装包保持官方签名，部署前由 Windows 验证。
• 普通代理使用系统代理/TUN 即可；仅 SOCKS 的代理需要开启 HTTP 混合端口或 TUN。
• 官方 MSIX 是该版本的完整安装包，已包含该版本的变更，不需要逐个安装历史补丁。发布说明是单独读取的文字资料。
• 若安装后仍显示“Update available”，先仅检查更新、比较本机版本和官方清单版本。发现更高版本时需完成对应更新；版本一致时再保存工作、完全退出应用（包括托盘）并重新打开，让应用刷新更新状态。

缓存与日志
侧栏和独立窗口使用相同的缓存状态：
• 已有最新版完整包：显示“已下载，待校验”。点击“校验并准备”直接复用，跳过安装包下载，继续许可证与签名校验；默认准备好后仍等待手动应用。
• 官方下载的包落后于实时最新版，且没有助手的有效完整缓存：保持正常未下载状态，显示“下载更新”，用灰色小字提示官方缓存的旧版本。助手自身有有效部分下载时显示“继续下载”。
• 两边都没有可用缓存：普通“未下载”状态，不显示额外警告。
• 只检查不复制、引用、下载安装包或许可证；实际点击准备时才引用缓存并重新验证。如果检查后官方包被清理或变动，准备阶段会安全回到正常下载。
• 同盘且文件系统支持时，助手与官方完整包通过硬链接共用同一份文件数据；不支持时从本机复制，无需重新从网络下载。助手删除引用不会删除官方文件，官方清理自己的路径也不会让助手已有引用失效。
• 只复用当前用户官方应用的 prepared.msix 完整缓存，不拼接下载中的文件，也不保证官方反向复用助手下载。Microsoft Store 自身的缓存不在此范围内；官方缓存位置变化时仍可正常下载最新版。

下载缓存：%LOCALAPPDATA%\ChatGPTInstallHelper\Cache
运行日志：%LOCALAPPDATA%\ChatGPTInstallHelper\Logs
侧栏插件来源：%LOCALAPPDATA%\ChatGPTInstallHelper\Sidebar
侧栏调用的助手副本：%LOCALAPPDATA%\ChatGPTInstallHelper\App\{助手版本}\ChatGPTInstaller.exe
下载完成并校验通过后保留完整缓存，等待手动安装；关闭安装助手也保留。重新打开时点击安装 / 更新以重新检查并复用缓存。
安装成功后删除助手自己的下载缓存或引用；不清理官方缓存。失败/取消保留有效缓存便于续传，验证为损坏的助手缓存会清除。最多保留 10 份日志。
不创建开机启动服务或计划任务。MCP 通信进程由 Codex 管理；实际更新由页面启动的独立助手进程继续执行，空闲后自动退出。
